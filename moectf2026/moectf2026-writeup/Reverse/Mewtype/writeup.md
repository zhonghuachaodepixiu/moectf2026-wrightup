## 核心校验逻辑

输入长度固定为 **54**（通过 `len(myk43) == 54` 检查）。

对输入的 54 个字符（ASCII 码值）进行如下校验：

1. **和校验**：所有字符 ASCII 码之和等于 `5138`。
2. **异或校验**：所有字符按顺序异或的结果等于 `26`。
3. **平方和校验**：所有字符 ASCII 码的平方和等于 `520600`。
4. **相邻乘积和校验**：相邻字符 ASCII 码乘积之和等于 `467644`。

此外，还有一个逐位置的三元组校验，通过一个长度为 54 的常数数组 T 以及索引 i 对字符进行分类：

- 当 `i % 3 == 0`：`a + b + c^2 == (T[i] ^ 90)`
- 当 `i % 3 == 1`：`a * b + c == (T[i] ^ 90)`
- 当 `i % 3 == 2`：`a^2 + b^2 + c^3 == (T[i] ^ 90)`
其中 `a = x[i]`，`b = x[i+1]`，`c = x[(i+17) % 54]`。

## 求解方法

这些约束是高度非线性的，但变量只有 54 个，且每个变量范围限制在可打印 ASCII（32~126），可以使用 **z3 SMT** 求解器 自动求解。

编写 z3 脚本：

- 定义 54 个 32 位位向量变量。

- 添加所有全局校验约束。

- 添加逐字符三元组约束。

- 指定可打印 ASCII 范围。

运行 z3，即可得到满足所有条件的字符串。

## 解密脚本

```py
from z3 import *

T = (
    10111, 11290, 137705, 13834, 12017, 882822, 2861, 6952, 148686,
    9290, 9962, 153274, 13069, 9595, 871218, 9834, 10851, 1584472,
    9149, 5765, 159511, 9289, 5093, 126222, 11887, 4921, 152566,
    13114, 6109, 140607, 13366, 9447, 156018, 9712, 11045, 1795540,
    15852, 4864, 1389923, 10278, 5369, 1586542, 10519, 5995, 1281695,
    4298, 5674, 963368, 10232, 5085, 880083, 10095, 15119
)

x = [BitVec(f'x{i}', 32) for i in range(54)]
s = Solver()

# 可打印 ASCII 范围
for v in x:
    s.add(32 <= v, v <= 126)

# 全局条件
s.add(sum(x, BitVecVal(0, 32)) == 5138)

xor_sum = x[0]
for v in x[1:]:
    xor_sum = xor_sum ^ v
s.add(xor_sum == 26)

s.add(sum([v * v for v in x], BitVecVal(0, 32)) == 520600)
s.add(sum([x[i] * x[i + 1] for i in range(53)], BitVecVal(0, 32)) == 467644)

# 逐字符约束
for i in range(53):
    a = x[i]
    b = x[i + 1]
    c = x[(i + 17) % 54]
    target = T[i] ^ 90

    if i % 3 == 0:
        s.add(a + b + c * c == target)
    elif i % 3 == 1:
        s.add(a * b + c == target)
    else:
        s.add(a * a + b * b + c * c * c == target)

if s.check() == sat:
    m = s.model()
    ans = ''.join(chr(m[x[i]].as_long()) for i in range(54))
    print(ans)
else:
    print("unsat")
```
